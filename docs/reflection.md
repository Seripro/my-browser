# 学習用ミニブラウザ 振り返り

## 完了したこと

- URLを入力して、HTTPまたはHTTPSのWebページを開ける。
- スキームなしの入力には`https://`を補う。
- ページ内リンクを開ける。
- 戻る、進む、再読み込みを実行できる。
- 戻る・進むの可否、読み込み中、読み込み失敗を画面で確認できる。
- ページ遷移の完了後、URL入力欄を表示中のURLへ更新できる。

## アプリ側が担当したこと

- SwiftUIでURL欄、操作ボタン、読み込み状態、エラー表示を描画する。
- URL入力を検証し、スキームの補完を行う。
- `WKWebView`の履歴状態やナビゲーション通知を受け取り、UIへ反映する。
- macOSのApp Sandbox内でWebへ接続できるよう、ネットワーク通信を許可する。

## WebKit側が担当したこと

- ネットワーク経由でページを取得する。
- HTML、CSS、JavaScriptを処理してページを描画する。
- ページ内リンクの遷移と閲覧履歴を保持する。

## 今回は対象外にした機能

- タブ、ブックマーク、履歴の永続保存
- ダウンロード、拡張機能、広告ブロック
- アカウント同期、複数ウィンドウ、ポップアップの制御
- 独自のHTML/CSS/JavaScriptレンダリングエンジン

## 次に追加する候補

- URL欄で入力中にページタイトルを表示する。
- ホームページを設定できるようにする。
- ブックマークをローカルに保存する。
